Modessi Design Your Bath page update

Install
1. Unzip this folder into the root of your Modessi project.
2. Merge the folders and allow the updated files to replace the existing ones.
3. Run your project with the command you normally use.

Included
- src/pages/design-your-shower.tsx — updated layout, larger step labels, automatic next-step navigation, and Moen finish images
- src/content/pages/shower_builder.json — bath builder content
- public/assets/uploads — shower base and bathtub product images

The Moen product images load from Moen’s image host, so the preview needs an internet connection.
